# 周边商圈

走出校门，武大周边汇聚了广八路、东湖新村、银泰、群光、乐天城、未来城、四眼井、街道口等多个美食商圈。从深夜烧烤到精致聚餐，总有一处适合你。

## 商圈导航

### 🍜 广八路

八一路+广埠屯合并，串串、热干面、烤鱼的深夜美食天堂。

[广八路美食 →](/surroundings/guangbalu/)

### 🏡 东湖新村

东湖边的宝藏村落，烧烤牛肉面，深夜烟火气十足。

[东湖新村美食 →](/surroundings/donghuxincun/)

### 🛍️ 银泰

大型购物中心，连锁餐厅集中，环境好适合约会聚餐。

[银泰美食 →](/surroundings/yintai/)

### 🏬 群光

群光广场中高端餐饮聚集地，海底捞、日式拉面应有尽有。

[群光美食 →](/surroundings/qunguang/)

### 🍲 乐天城

信部同学的觅食宝地，潮汕牛肉火锅和蜜雪冰城是招牌。

[乐天城美食 →](/surroundings/letiancheng/)

### 🏙️ 未来城

武大南门旁的商业综合体，兰州拉面、瑞幸咖啡方便快捷。

[未来城美食 →](/surroundings/weilaicheng/)

### 🌙 四眼井

老社区过早一条街，早餐天堂+深夜烧烤大排档。

[四眼井美食 →](/surroundings/siyanjing/)

### 🚇 街道口

交通便利的商业中心，连锁餐厅集中，约会聚餐首选。

[街道口美食 →](/surroundings/jiedaokou/)
