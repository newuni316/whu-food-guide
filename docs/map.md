## ✨ 功能说明

### 🎨 区域颜色标记
地图上的标记按校区/商圈自动着色，方便快速区分：
- 🔴 **文理学部**（梅园、桂园、枫园、樱园）
- 🔵 **工学部**
- 🟢 **信息学部**
- 🟠 **医学部**
- 🟣 **周边商圈**（八一路、广埠屯、街道口等）

### 🔍 搜索与筛选
- **搜索框**：输入餐厅名称快速定位，点击搜索结果自动跳转并打开详情
- **区域筛选**：勾选/取消校区区域，动态显示/隐藏对应标记
- **评分筛选**：选择最低评分，快速找到高分餐厅
- **计数显示**：实时显示当前可见餐厅数量

### 🎯 地图控制
- **全部按钮**：一键恢复所有标记并自适应视图
- **缩放控制**：右上角 +/- 按钮，或双指缩放
- **点击标记**：查看餐厅详情卡片（评分、人均价格、推荐菜品、标签）

### 📱 响应式设计
- 桌面端：地图高度 700px，筛选面板固定在左侧
- 移动端（< 768px）：地图高度 500px，筛选面板折叠为浮动按钮

## 使用技巧

1. 点击任意标记查看餐厅详情和推荐菜品
2. 使用搜索框输入名称可以快速定位到某个餐厅
3. 通过区域和评分筛选缩小选择范围
4. 点击 🎯 按钮可以查看所有标记的全景视图
